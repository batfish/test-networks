The Bagpipe revision documents the earlier source repository and its
license. Expresso reports that lineage; the original operator capture
and byte-level history back to it are not established here. The
[Internet2 source notes](networks/internet2/SOURCES.md) state that limit.

The Freedome generator is repository-authored code inspired by referenced
publications. The WAN composition generator is repository-authored code
that documents REAL's graph-composition method. Upstream REAL, S2, ACORN,
and Propane code is not bundled.

Publications are cited by links and bibliographic descriptions. Their
PDFs are not redistributed in this repository.
