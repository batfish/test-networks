# Archived Batfish fattree20

Historical generated Cisco-style BGP configs with 500
routers. The original [fattree20.zip](fattree20.zip) is preserved byte-for-byte.
[Source notes](SOURCES.md) identify its upstream path, revision, and
unknowns. The upstream [Apache-2.0 license](LICENSE) is kept here.

The archives were added in [batfish/batfish#842](https://github.com/batfish/batfish/pull/842).
Larger fat-tree archives were later removed from master in
[batfish/batfish#2367](https://github.com/batfish/batfish/pull/2367).
This data comes from the retained `abstract-interpretation` revision.

Load the archive as described in the [repository README](../../README.md).
ZIP integrity, source blob identity, and config-file count were checked.
Current parser behavior is unverified. The original generator was not
recovered in the inspected sources; this is a fixed snapshot.
